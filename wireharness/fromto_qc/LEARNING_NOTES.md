## 2. 確定した作図仕様（御社の実証済みシミュレーター準拠）
`geometry.py` は既にこの仕様に一致済み。
- 配線画層 `WIRE_LAYERS = {L_CONTROL, L_MAIN, L_OUTSIDE}`（+主回路で L_EARTH/DENSEN）。
- しきい値: `POINT_TOL=5`（節点）, `TERMINAL_TOL=15`（端子台 `_LU*`）, `SENBAN_SEG_MAXDIST=250`（線番→配線）。
- 接続機構: `_crossPoint1`=T字接続、`_LU*`=端子台中継（内部 L_CONTROL ⇔ 外部 L_OUTSIDE 橋渡し）。
- 機器キー = `DEVICE|DEVICE1|DEVICE2`。端子 = `TB` 相対座標をワールド展開。
- 電源判定 = `L_MAIN` に繋がる線番。R/P=hot, S/N=neutral。
- 検図ルール E1〜E11（電源未到達・孤立端子・線番不整合 等）。

## 3. 二層モデル（実データで裏付け）
- **ハーネスデータ = 論理 From-To**（号線・機器・端子）。設計レベル。
- **ハーネスシートデータ = 物理・製造ハーネス** = 論理 + 製造ルール適用。製造工程が使う最終成果物。

### ハーネスシートの列（tab区切り, cp932）
`号線/線色 | (号線接尾) | サイズ/種別 | 方向/位置 | 機器記号 | 機器番号 | 端子(+方向)`
- 方向/位置: `扉 / 右 / 左 / 上 / 下 / 外`、端子側にも `1R 上` `E_下` 等の**ダクト方向**。
- 電線種別: `KIV / HIV / IV / TGV / 丸棒 / ツイスト / SPEV(シールド)`。
- グループ見出し `* * <種別> <サイズ> <色>`、`ダクト 外` 等。

## 4. 製造ルール（シートデータで実証）
| ルール | 実データ例 |
|---|---|
| 盤間・主回路(電源) → **LUG** | `赤 LUG → MCCB102-1`（4-21088 多数） |
| 盤間・制御 → **WAGO/コネクタ** | `1R2 WAGO 右 MCCB-1`（4-21088） |
| 端子3本以上 → **中継/渡り** | `TB 中継11`（5-12110）, `中欠用TB`（5-12073） |
| 扉付け機器 → **扉フラグ** | `1S 扉 BZ / OL / WL`（各セット） |
| **ダクト方向** 上/下/左/右/外 | `1R 上/1R 下`, `E_下`, `P1_上`（内部配置図の機器⇔ダクト座標から決まる物理情報） |
| 標準追加部品 | `FAL1`（AL1ヒューズ）等が人手で追加（29026でも検出） |

## 5. 照合の実測（wire-trace=論理 vs 人手シート=物理）
| セット | 整合率(機器edge) | 浮き線端 |
|---|---|---|
| 5-29026 | 41% | 121 |
| 5-12110 | 10% | 268 |
| 4-21088 | 7% | 136 |
| 4-29033 | 5% | 340 |

**低い直接一致は「失敗」ではなく「設計→製造の差」が主因**：LUG/WAGO/中継/扉/ダクトは論理接続に存在しない製造付加。
その差こそが学習対象（第4章の製造ルール）。加えて、
- **浮き線端**（wire端が端子に届かない）は論理層の品質問題＝検図E3。
- **名称ゆらぎ**（`A/B/C`, `○`付き, `切/入`, `FAL1`）はセットごとの別名辞書で吸収。

## 6. 方針（この学習からの結論）
1. **論理 From-To の検証は論理層で行う**（物理シートと直接一致で測らない）。検図E3で浮き線端を品質ゲート。
2. **製造ルールエンジン**（論理→物理）を7セットの差分から学習・実装：LUG/WAGO/中継/扉/電線種別。
3. **ダクト方向**（上/下/左/右）は内部配置図の `DCT`（ダクト）と機器座標から計算して付与。
4. 最終成果物 = **ハーネスシートデータ**（製造工程がそのまま使う形）。
