# ハーネス太物データ一式 ルール精査(2026-10)

工程資料「ハーネス太物データ一式」(10製番)を解析・学習した結果と、ルール(アルゴリズム)の
精査・改修方針。目的: 人の確認項目を削減し、2人目(端子番号)・3人目(FromTo)を自動化する。

## 受領データ(製番フォルダ単位)

| # | ファイル | 形式 | 当方での扱い |
|---|---|---|---|
| ① 図面データ_ | DXF (D/E/F, 分電盤 G/H) | 解析可(主入力) |
| ② 機器相番号_…DCT | DWG→DXF変換 | ロケーター(仮名称)・相番号の源 |
| ③ 接点手書き追記…スキャン | PDF(手書き) | 要Vision(3人目の接点追記=手作業) |
| ④ FromToデータ_ | TXT | **人の正解**(3人目成果) |
| ⑤ 太物経路_ | DWG→DXF変換 | 太物経路ジオメトリ＋実配線長(1人目) |
| ⑥ 太物寸法表_ | PDF(表) | 太物加工指示(要Vision/表抽出) |

10製番(うち2製番「太物無し」)。④の実配線=1194本、一意エッジ約1119。

## 確立したこと

### 1. DWG→DXF 変換(前処理)
②⑤がDWG(AC1027=AutoCAD2013)で届く。ezdxfはDWG不可のため、GNU LibreDWG `dwg2dxf` を
ローカルビルドして変換(データは外部に出さない)。全18DWGを属性保持DXFへ100%変換。
→ `dwg_convert.py` / `DWG_CONVERT.md`(ビルド手順)。

### 2. 太物ルールの実データ裏付け ◎
- ④FromToの電線サイズは {0.75,1.25,2,3.5,5.5} のみ、**最大5.5sq・8sq以上ゼロ**(全10製番)。
- ⑤太物経路＋⑥寸法表は、太物のある8製番に存在し「太物無し」2製番には無い。
→ 「ハーネスFrom-To(3人目)=5.5sq以下だけ。太物(≥8sq)は別工程(1人目=⑤⑥)」という
  太物しきい値(5.5sq)が実作業者データで確証された。`wire_select`/`tb_phase` の境界を固定。

### 3. ④正解ローダ＋端子語彙学習
- `fromto_truth.py`: ④(号線/色/marker/長さ(+マーカー有無)/扉/機器/番号/端子, 渡り分割)を
  正規化エッジ化。採点・学習の共通基盤。
- `harness_learn.learn_terminals(merge=True)`: ④から端子語彙を**追加のみ**で学習。
  機器種別 84→85(GOR追加)、TB端子 236→286、ﾏﾙﾁ語彙拡張。既存の喪失ゼロ。
  → 2人目(端子番号付与)の候補網羅が向上。

### 4. カバレッジ/差分分類(ルール精査の採点) — `fromto_coverage.py`
④エッジ1119本を「両端の機器が設計DXFに在るか」で分類:

| 種類 | 割合 | 意味 / 対応 |
|---|---|---|
| both_in_dxf | **65.8%** | 再現可能の母体(ここを主回路生成＋制御トレースで埋める) |
| fixed(BOX/LUG/SPD/分離器) | 11.1% | 固定特殊端点。語彙で既知化すれば加点(易) |
| locator(A,B,C…仮名称) | 10.5% | ②DCT/内部配置図の凡例で実機器へ対応。部分解決済、D001併用で改善 |
| multi(マルチ計器 等) | 9.4% | 別シート/別記号。機器対応の個別対応が要 |
| other | 2.6% | 切/入/伝送/タイマ 等の個別機器 |
| new(GOR) | 0.6% | 新機器。要調査 |

機器(ベース)粒度では ④機器の約83%が設計DXFに実在(＝多くは「番号・符号の食い違い」で
真の欠落ではない)。例: ④`ELCB-○LG03` ↔ 図面`ELCB`(番号表記違い)、④`A` ↔ 図面`ALX`(ロケーター)。

### 5. 太物経路(⑤)
変換後DXFのLWPOLYLINEが ELCB/MCCB↔Lug↔TB(主回路太物=LUG→遮断器→TBの経路)を描画。
`main_circuit` が生成する主回路トポロジと一致。各経路は実配線長(点列長 ≈ mm)を持ち、
**将来の線長精度向上(1人目自動化)の実測材料**になる。

## ルール精査の結論と改修優先順位

再現率を上げる効き目の大きい順:
1. **固定端点の語彙化**(BOX/LUG/SPD/分離器, +11%): DEVICE属性を持たない特殊点を既知端点として
   扱う。低リスク・即効。
2. **ロケーター解決の強化**(+10%): ②DCTだけでなく①D001内部配置図の凡例も併用し、
   A,B,C…→実機器(ALX/86X/CX…)へ。設計DXFは実記号を持つので対応表さえ揃えば接続。
3. **遮断器の記号正規化**(○◎・枠番号 LG/CE/CG/LE): ④ラベルと図面DEVICE1の対応規則化。
4. **マルチ計器の機器対応**(+9%): マルチの端子・接続の取り込み(別シート確認/Vision)。
5. **③手書き接点**: 3人目が手書きで足す接点は設計DXFに無い。Vision読み取り or 確認UIの
   接点入力欄で人の確認として残す(どちらを採るかは要相談)。

## 残課題
- ③接点手書きスキャン: Vision読取の精度検証(手書き)。
- ⑥太物寸法表PDF: 表抽出(太物の確定・加工指示)。
- 線長精度: ⑤の実配線長を活用した測長モデル(ダクト経路・扉跨ぎ)。
