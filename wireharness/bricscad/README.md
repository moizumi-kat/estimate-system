# BricsCAD From-To 書き出しアドオン（fromto.lsp）

BricsCAD の図面（シーケンス／スケルトン）から、電線ネットをたどって
**From-To（結線）表**を CSV で書き出し、あわせて**接続確認（検図）**を行う
AutoLISP アドオンです。コンパイル不要、APPLOAD で載せるだけ。

## 載せ方
1. BricsCAD で対象図面を開く
2. コマンド `APPLOAD` → `fromto.lsp` を選んでロード
   （またはコマンドラインで `(load "C:/…/fromto.lsp")`）
3. `FROMTO` と入力して実行

## 出力（図面と同じフォルダ）
| ファイル | 内容 |
|---|---|
| `<図面名>_fromto.csv` | From-To 結線表 |
| `<図面名>_kenzu.txt`  | 検図レポート（要確認箇所） |

### CSV の列
```
号線, サイズ, 機器記号, 機器番号, 端子番号
```
人手ハーネスデータと同じ並びなので、検図システムにそのまま取り込めます。

### 検図レポートで指摘する項目
- **[浮き線端]** … 電線の端が機器端子に届いていない（結線が確定できない）
- **[端子未接続]** … 機器の端子に電線が来ていない
- **[号線なし]** … 電線ネットに線番タグが付いていない
- **[片接続]** … その号線が機器1つにしか繋がっていない（相手先不明）

これらを図面で直す（電線端を端子にスナップ／主回路機器に端子点を持たせる／
線番を付ける）ほど、From-To の行数が増え、精度が上がります。

## 仕組み
1. 電線（LINE/LWPOLYLINE）を連結でたどってネット化
2. 機器ブロックの端子ピン（`DEVICE`＋`TERMINAL*`＋`TB` オフセット）を算出
3. 電線ネットの端を、近い端子にスナップして結線を確定
4. 号線タグ（`線番`／`SOU`）を各ネットに割り当て
5. 確定した結線を CSV に、確定できない箇所を検図レポートに出力

## 調整（作図規約に合わせて `fromto.lsp` 冒頭を編集）
```lisp
(setq *FT-WIRE-LAYERS* "L_CONTROL,L_MAIN,L_EARTH")  ; 電線画層
(setq *FT-TOL*     8.0)   ; 電線どうしの連結許容距離
(setq *FT-SNAP*   25.0)   ; 電線端→端子 スナップ許容距離
(setq *FT-TAGMAX* 60.0)   ; 号線タグ→電線 最大距離
```

## 補足（設計思想）
BricsCAD の DXF には「電線↔号線↔機器端子」の紐付けが保存されていないため、
本ツールは図面の幾何から結線を復元します。より確実にするには、
**採番アドオン側で、採番時に確定している結線をそのまま CSV 出力する**のが理想です
（幾何復元が不要になり、ほぼ 100% になります）。本 LISP はその移行前でも、
既存図面から結線を取り出しつつ「直すべき箇所」を可視化する位置づけです。
