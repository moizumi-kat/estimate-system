# 記号認識テンプレート（advisory）

確認ビューアで図面上の機器記号を**テンプレートマッチングで検出・色分け**するための記号ライブラリと設定です。

## 重要（安全性）
- **advisory 機能**です。積算額・コード選定には**一切関与しません**（選定エンジン不変＝回帰ゼロ）。
- OpenCV が無い本番では**自動で無効化**され、ボタンは「サーバにOpenCVが必要」と表示するだけ（既存機能に影響なし）。
- 位置・台数は**概略の当たり付け**。最終確認は人の目視。

## 構成
- `*.png` … 機器記号glyphのテンプレート（15機種）
- `config.json` … 機器別の色(BGR)・一致閾値・スケール
- `manifest.json` … 各テンプレのJIS番号・照合結果
- 検出/着色ロジックは リポジトリ直下 `symbol_detect.py`

## 記号の境界ルール（JIS/JEM規格で裏取り）
記号本体（接点/丸/箱/コイル）だけが記号。**接続線（リード・配線）は記号ではない**ので、着色・検出から除外（貫通配線・母線はモルフォロジーで除いて黒のまま）。

## 規格照合（JIS C0617 / JEM1115・1090）
TR=06-09-01（二重丸）, VCB=07-13-05, DS=07-13-06, CT=06-09-10, ZCT=06-13-10, VT=06-13-01,
SC=04-02-01, SR=04-03-01, VMC=07-13-02, LBS=07-21-09。
→ 核記号は規格と一致。御社支給図面は開閉機器を**箱囲み**で描く流儀のため、核記号＋箱でテンプレ化（実図面に一致）。

## 本番でのOpenCV導入（着色を有効にする場合）
EC2（python3.11系）に以下を入れると `/api/symcolor` が有効になります：
```
pip install opencv-python-headless numpy
```
未導入でもシステムは正常動作します（ボタンが無効メッセージを返すのみ）。

## 使い方（ビューア）
「📄 図面と並べて確認」→「🎨 記号で着色(AI)」で、現在ページの機器記号を機器別色で着色し、検出数を表示。もう一度押すと元図面へ戻ります。

## 検出網羅（神田の杜E-001で実測）
主要機器 TR4/SC2/SR2/VMC2/LBS4/ELR4/VCB1/DS1/VT1 を100%・誤検出ゼロ。
計器・CT等の「丸＋文字」型は繰り返し部で部分検出（文字OCR併用が本筋）。
