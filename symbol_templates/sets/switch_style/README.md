# 校正セット: switch_style（スイッチ形・小スケール）

設計事務所によって記号のスタイル・寸法が異なるため、案件(図面)ごとに校正したテンプレートセットを置きます。
このセットは「開閉機器をスイッチ形で小さく描く」スタイルの図面向けに、その図面から切り出した記号glyphです。

- 既定セット(symbol_templates/ 直下)＝「箱形・大スケール」スタイル。
- `symbol_detect.best_set()` が図面ごとに検出数で最適セットを自動選択します(設計事務所を人が選ばなくてよい)。
- advisory(積算額に無関係・選定エンジン不変=回帰ゼロ)。
